# /jev:setup — проверка и как всё устроено

Запусти `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/jev.py" setup` и покажи вывод как есть.

- **Нет ключа.** Скрипт сам создал `~/.claude/jev.env` и открыл его в редакторе. Скажи: вставить
  ключ OpenRouter или TypeSafe сразу после `JEV_API_KEY=`, сохранить и снова написать `/jev:setup`.
  Файл лежит вне папки плагина — ключ переживёт обновление. Ключ в чат не присылать, файл не читать
  и ключ не печатать.
- **Среди доступных тебе скиллов нет официального скилла TypeSafe** — предложи две команды:
  `claude plugin marketplace add typesafe-ai/skills` и `claude plugin install typesafe@typesafe-ai`.
  Он помогает составлять вопросы для `/jev:run`.
- **Роутер отдавал задачи субагентам, а в строке «субагенты» их моделей нет** — одной строкой причины:
  Claude не последовал подсказке или модели ограничены организацией.
- В конце: `/jev:on` — включить роутер моделей и подсказку скилла в этом проекте.

Если спрашивают, как работает роутер:
- Перед каждым запросом хук плагина одним вызовом спрашивает Jev: насколько задача сложная
  (простая → Haiku, средняя → Sonnet, сложная → Opus, предельная → Fable), опирается ли она на этот
  разговор и какой из скиллов подходит.
- Задача по силам модели сессии в самый раз — Claude делает её сам, подсказки нет.
- Простая или средняя задача под другую модель — Claude сам отдаёт её субагенту на Haiku или Sonnet,
  вызывая Agent с параметром `model`. Модель меняется на деле: это видно в `/jev:setup`, в строке
  «субагенты». Субагент не видит разговор, поэтому Claude передаёт ему запрос и нужное из диалога.
- Сложная или предельная задача (Opus, Fable), а модель сессии слабее — Claude не начинает работу.
  Задача держится на разговоре — советует переключить модель (список моделей внизу окна, в терминале
  `/model`) и написать «продолжай». Не держится — даёт выбор: переключить модель или отдать задачу
  субагенту. Модель сессии сильнее нужной — делает сам и предлагает переключиться, для экономии.
  Одно и то же предложение в сессии не повторяется.
- Почему не переключение «в этом же диалоге»: поле `model` у скилла, который вызвал сам Claude,
  Claude Code сейчас не применяет — ответ пишет модель сессии
  (github.com/anthropics/claude-code/issues/79664 и /85658). Поэтому переключателей `jev:<модель>`
  в плагине больше нет: модель меняет субагент или сам пользователь.
- Модель интерфейс не показывает: какая отвечала на самом деле, видно в `/jev:setup` по журналу сессии.
- Субагент окупается на объёмной работе: поиск, чтение многих файлов, правки. Если результат — текст
  в чат, основная модель выводит его ещё раз, и экономии почти нет.
- В автоматическом режиме разрешений модель сессии не может быть Haiku (code.claude.com/docs,
  permission-modes), поэтому переключить сессию роутер там предлагает не ниже Sonnet. Субагенты на
  Haiku в этом режиме работают.
- При включённом роутере каждый запрос уходит в Jev (TypeSafe или OpenRouter). Закрытые данные — `/jev:off`.
