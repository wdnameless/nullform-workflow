# /jev:run — решение по каждой записи, одной командой

Jev не пишет текст, он отвечает на вопросы в трёх формах: **да/нет** (вероятность), **выбор** из
вариантов (распределение и уверенность), **шкала** по ступеням. Прогон делает скрипт
`python3 "${CLAUDE_PLUGIN_ROOT}/scripts/jev.py"` (дальше — `jev.py`); ключ он находит сам, в чат его не проси.

**Одна команда — сразу результат.** Не устраивай интервью и не разбивай на «создать» и «запустить».

1. **Данные.** Файл или папка названы — бери. Не названы — это единственное, о чём спросить.
   Загляни в 3–5 записей сам: какие поля есть, на каком языке текст. Excel — попроси сохранить
   как CSV. Папка — каждый текстовый файл становится записью `{file, text}`.
2. **Первое слово — имя сохранённой задачи** (раздел `tasks` в `.claude/jev/questions.json`
   проекта) — сразу шаг 4.
3. **Вопросы — сам, по чек-листу** `${CLAUDE_PLUGIN_ROOT}/references/чек-лист.md`: действия →
   триггер каждого → какие поля смотрит человек (`fields`) → крайние случаи → цена ошибки (порог).
   Формулировки — по официальному скиллу TypeSafe, если он тебе доступен (разделы «Design the
   judgments» и «Compose and verify»), иначе — по `${CLAUDE_PLUGIN_ROOT}/references/вопросы.md`.
   Формат задачи — `_шаблон_задачи` в `${CLAUDE_PLUGIN_ROOT}/questions.json`. Запиши задачу под
   коротким латинским именем в раздел `tasks` файла `.claude/jev/questions.json` проекта: нет
   файла — создай `{"tasks": {…}}`, остальное в файле не трогай. Переспроси пользователя, только
   если из запроса нельзя понять, какие решения нужны.
4. **Прогон — сразу весь объём:** `jev.py run <имя> <файл или папка>`, для папки можно
   `--glob "*.md"`. Пробных прогонов на части записей не делай: Jev стоит доли цента на сотни
   записей, и повторить весь прогон дешевле и быстрее, чем пилот. Если по результату видно, что
   вопрос понят не так, — поправь формулировку и прогони всё ещё раз.
5. **Спорное — сам.** В результате (`<файл>.jev.csv`) записи с «перечитать = да»: уверенность ниже
   `review_below` или да/нет в зоне `noul_unsure`. Прочитай их и допиши своё решение отдельной
   колонкой, ответы Jev не перезаписывай.
6. **Итог одним сообщением:** распределение ответов, что перечитал ты, стоимость, файл результата,
   вопросы к Jev — по строке. В конце одна строка: повторить — `/jev:run <имя> <файл>`, проверить
   на разметке — `/jev:check`.

## Границы — говори о них прямо

- **Русский язык.** Основной язык обучения Jev — английский, другие языки он понимает хуже
  (docs.typesafe.ai/models). Для русских текстов пороги ставь осторожнее и предлагай `/jev:check`.
- **Контекст:** 64 тыс. токенов на запрос у TypeSafe, 32 тыс. через OpenRouter и Vercel.
- **Выбор — до 255 вариантов, шкала — от 2 до 10 ступеней.** Больше — дели на два вопроса.
- **Цена:** $0,042 за миллион входных токенов, выход бесплатный.
