# /jev:check — проверка на своих данных

Правильные ответы человека — колонки `ответ_<вопрос>` в файле: для да/нет «да»/«нет», для выбора —
вариант, для шкалы — номер ступени с 1. Нет размеченного файла — помоги собрать: 30–100 записей,
которые уже разобрал человек, или выборка на разметку.

Сравнение с Sonnet — по желанию: субагент с `model: "sonnet"` получает те же записи и те же вопросы
с вариантами (из задачи) и заполняет колонки `sonnet_<вопрос>`, не видя колонок `ответ_…`.

Затем `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/jev.py" check <имя задачи> <файл>`, при сравнении —
с `--compare sonnet`. Отчёт — `<файл>.check.md`: совпадения Jev (всего и без спорных записей),
Sonnet и расхождения. Разбери их с пользователем: чаще всего вопрос размыт и Jev прочитал его
буквально — допиши критерий в задаче (`.claude/jev/questions.json` проекта) и прогони сверку ещё раз.
Не обещай, что Jev точнее Sonnet: решают цифры сверки.
