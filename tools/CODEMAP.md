# tools/

## Responsibility
CLI Toolchain, Governance Facade, and Diagnostic Harness for the OMP workflow. Provides drift synchronization, tier-based SDD workflow enforcement (T0–T3), subagent coordination and task leasing, cross-harness adapter configuration, transactional packaging and release certification, benchmark and replay evaluation, candidate mutation optimization, cognitive complexity and quality gating, offline dependency manifest diagnosis, offline skill security scanning, local gate tallying, and real-time observability dashboards for agent operations. Houses non-codemapped submodules for cross-harness configuration mutators (`tools/installation/`), controlled review arbitration (`tools/review/`), multi-stack quality analyzers (`tools/quality/`), and concurrent subagent coordination (`tools/workflow/`).

## Design Patterns
- **CLI Toolchain & Workflow Core Partition**: Subcommand routers (`workflow.mjs`, `sync.mjs`, `codemap.mjs`, `jev-control.mjs`, `worktree-doctor.mjs`) coordinating child processes, git status queries, and repository state. The workflow engine is partitioned into `workflow.mjs` (CLI command dispatcher, tier laddering T0–T3, artifact validation, interactive prompts), `workflow-ci.mjs` (CI gate enforcement, `check-ci`, `checkQualityGates`, `cmdSettle`), and `workflow-core.mjs` (shared state persistence, file constants `DIR`, `FILE`, `BUDGETS_FILE`, `METRICS_FILE`, lock coordination `withStateLock`, state persistence `load`/`save`, `logEvent`, tier heuristics `suggestTier`, session accounting `parseSessionUsage`, and artifact validation `validateArtifacts`, `validateOpenspecArtifact`; imports `session-log.mjs`, `worktree-snapshot.mjs`, `requirements.mjs`, and `review/evidence.mjs`; consumed by `workflow.mjs` and `workflow-ci.mjs`).
- **Modular Observer & Cockpit Server (Dashboard Split)**: `dashboard.mjs` serves as HTTP daemon and lifecycle coordinator with route dispatch (`/api/state`, `/api/diff`, `/api/arch`, `/api/arch/drill`, `/api/arch/svg`), delegating to specialized modules: `dashboard-collectors.mjs` for protocol versioning, git metrics, and host security (`isAllowedHost`); `dashboard-needed.mjs` for human action gap analysis; `dashboard-ui.mjs` for HTML cockpit rendering; `dashboard-shell-client.mjs` for CSS, client JS, and RU/EN i18n dictionaries; `dashboard-sketch.mjs` for procedural Excalidraw-like canvas geometries; and `dashboard-arch-client.mjs` along with `arch-drill.mjs` for AST symbol drill-down (`collectArchDrill`, `collectSymbolInventory`, `isBinaryName`).
- **Layered Diagnostic Probe & Dependency Doctor**: Diagnostic ecosystem separated into `doctor.mjs` (CLI driver, provider reachability, formatted terminal output), `doctor-checks.mjs` (16 isolated environment and wiring health checks), `doctor-lite.mjs` (fast lightweight preflight probe for workflow turns), and `doctor-shared.mjs` (`CORE_TOOLS`, `REQUIRED_ROLES`, path normalization, BOM stripping); supplemented by `worktree-doctor.mjs` (worktree pruning), `skills-doctor.mjs` (skill registry integrity), `cache-doctor.mjs` (cause code analysis), `cache-policy.mjs`, and offline dependency diagnosis via `dependency-doctor.mjs` (`diagnoseRequirements`, `diagnosePyproject`, `diagnosePackageJson`, `diagnoseManifests`, `PYTHON_STDLIB_MODULES`, `NODE_BUILTIN_MODULES`, `OBSOLETE_BACKPORTS`).
- **Offline Skill Security & Registry Governance**: `skill-security.mjs` provides static offline scanning, eval checks, and trigger evaluation without external network calls, exporting `scanSkillSecurity`, `auditSkillEvals`, `evaluateSkillTrigger`, `evaluateSkillTriggerFixtures`, and `lintSkillRegistry` (imports `parseSkillFrontmatter` from `skill-audit.mjs`; part of a known import cycle `skill-audit.mjs` <-> `skill-security.mjs`); supplemented by `skill-audit.mjs`, `skills-doctor.mjs`, and `skills-lock.json` validation.
- **Deterministic Lifecycle Evaluations**: `lifecycle-evals.mjs` validates core workflow state transitions (R01–R03) across synthetic fixtures, defining `LIFECYCLE_CASES` and `runLifecycleEvals` for pickup claim verification (`evalPickupClaim`), double-claim conflict detection (`evalDoubleClaim409`), approval denial path (`evalApprovalDeny`), and exponential backoff retry calculation (`evalBackoffRetry`, `computeBackoff`).
- **Local Gate Telemetry & Tallies**: `gate-counter.mjs` implements append-only local JSONL tallies for gate evaluations without external network or PII leakage, exporting `resolveLogPath`, `recordGate`, `readGateCounts`, `tallyCounts`, and `formatTally`; consumed by `workflow.mjs` and CLI entrypoints.
- **Adapter & Transactional Packaging (`installation/`)**: `tools/installation/` manages cross-harness lifecycle across 8 target engines (`adapters.mjs`, `capabilities.mjs`, `config.mjs`, `journal.mjs` with `deployment.lock`, `state.mjs`, `profiles.mjs`, `restore.mjs`, `hermes-policy.mjs`); paired with `install-harness.mjs` and `install-store.mjs` managing prepared store reuse and deployment plans (`STORE_MARKER`, `isPreparedStore`, `writeStoreMarker`, `applyStorePlan`).
- **Multi-Stack Quality Dispatcher & Gatekeeper (`quality/`)**: `quality.mjs` is a dispatcher that re-exports `./quality/engine.mjs` wholesale; `quality/engine.mjs` owns technology stack discovery (`quality/stacks.json`), sidecar configuration management, analyzer execution, baseline persistence (`loadBaseline`, `saveBaseline`), and cognitive complexity ratchet enforcement (`applyRatchet`); paired with `contrast-check.mjs` (WCAG 2.x), `code-size.mjs`, `mutation-test.mjs`, and `debt-ledger.mjs` (`# ponytail:` tracking).
- **Benchmark Harness, Candidate Optimizer & Replay Sandbox**: Empirical LLM evaluation suite (`benchmark.mjs`, `benchmark-run.mjs`, `bench-smoke.mjs`, `bench-analytics.mjs`, `bench-budget.mjs`, `bench-results.mjs`, `bench-session-runner.ts`, `replay.mjs`, `run-skill-benefit-eval.mjs`, `orchestrator-evals.mjs`) executing native SDK runs with tariff tracking; augmented by `bench-optimizer.mjs` (`runCandidateOptimizer`, `generateOneMutation`, `checkAdmittedProvider`, `BUILTIN_MUTATION_OPERATORS`) for AST-guided candidate code/skill mutation runs. Contains known three-way import cycle `bench-analytics.mjs` <-> `bench-smoke.mjs` <-> `benchmark.mjs`.
- **Security Hardening & Containment**: Subprocess invocations in `domain-context.mjs` enforce strict argument vector arrays (`execFileSync` replacing shell strings) to eliminate shell metacharacter injection; cassette replay in `lm-replay.mjs` resolves and checks destination path containment (`isPathInsideRoot` semantics) against repository escape traversal, while replay servers (`replay.mjs`) and dashboard HTTP servers bind loopback `127.0.0.1`.
- **Strategy & Verification Profiles**: Pluggable verification strategies split between `verify.mjs` (dispatcher), `verify-profile.mjs` (deep verification suite), `audit-profile.mjs` (auditing passes), and `verify-shared.mjs` (shared execution helpers), alongside tier-specific SDD workflow rules (`workflow.mjs`, `tripwire.mjs`) and subagent return contract enforcement (`return-contract.mjs`).
- **Subagent Task Coordination & Workspaces (`workflow/`)**: `workflow/claims.mjs` manages lease-locked task claims (`claimTask`, `releaseTask`) and context packets across parallel subagents; `workflow/workspaces.mjs` isolates execution workspaces and worktree lifecycles.
- **Controlled Review & Financial Authority (`review/`)**: `tools/review/` enforces bounded review execution: `review/budget.mjs` acts as the single financial authority tracking token ledgers; `review/gatekeeper.mjs` intercepts dangerous tool invocations; `review/http-runtime.mjs` and `review/http-child.mjs` run sandboxed direct HTTP completions; `review/native-tools.mjs` provides in-process product inspections (`inspectProduct`, `executeProduct`, `readProductPage`); `review/evidence.mjs` and `review/http-evidence.mjs` generate cryptographic receipts; `review/evidence-history.mjs` validates git lineage; and `review/arbitrate.mjs` arbitrates verdicts and computes F1 scores. Compaction via `review/ledger-compact.mjs` folds settled rows to maintain ledger size ceilings.
- **Judicial Evidence Verification (JEV) Suite**: `jev-control.mjs`, `jev-assist.mjs`, `jev-evaluate.mjs`, `jev-evaluation-cases.mjs`, and `jev-evidence.mjs` automate paired empirical evaluation and policy validation for agent skill triggers.
- **Changed-Scope CI Gate Family (Strategy + Template Method)**: one shared scope resolver, two gates. `changed-scope.mjs` is the single home of git-diff scoping and suite matching (`resolveBaseRef`, `gitDiff`, `getChangedFiles`, `getChangedLines`, `findMatchingSuite`, `filterCandidateFiles`); `mutation-changed.mjs` (bounded mutant budget per changed file) and `coverage-changed.mjs` (min changed-line coverage, default 50%) are Template Method consumers, both exiting 0 fast when nothing changed.
- **Duplicate Detection & Ratchet Baseline**: `clone-coverage.mjs` is a Type-1/Type-2 clone detector (`normalizeLine`, `tokenBlindHash`, `scanClones`, `scanClonesWithDetails`) with an explicit honest boundary in its header, gated by a baseline ratchet (`loadCloneBaseline`, `buildBaseline`, `checkClones`, thresholds `minLines: 10` / `failLines: 35`). Shares the source scanner with `code-size.mjs`.
- **Route Resolution & Delivery Metrics**: `model-router.mjs` resolves model categories by walking priority chains (`resolveCategory`, `isModelAvailable`, `MODEL_STOP_QUESTION`), with probe, plan, and apply commands (`scanProviders`, `planCategories`, `applyCategories`). Delivery metrics: `cfr-report.mjs` (Change Failure Rate from conventional commits; a `fix` within 48h of a `feat` counts as post-merge fix) and `lead-time.mjs` (per-tier start→close medians, ask→answer pauses, artifact-oracle→close, from `.workflow/events.jsonl`).
- **Harness Probe (Clean-Room Port)**: `harness-probe.mjs` (`probeHarness`, `satisfiesMin`, `defaultRunner`) detects installed CLI harness versions via an injectable runner without external code; consumed by `bin/nullform.mjs` and `doctor.mjs`.

## Data & Control Flow
1. **Entry & Subcommand Routing**: CLI scripts (`workflow.mjs`, `verify.mjs`, `sync.mjs`, `doctor.mjs`, `dashboard.mjs`, `bin/nullform.mjs`) parse args, validate runtime environment (`preflight-env.mjs`, `sanitize-text.mjs`), and resolve configurations (`agent/models.yml.example`, `sync-manifest.json`, `skills-lock.json`).
2. **Harness Setup & Transactional Store Deployment (`installation/`)**: `install-harness.mjs` and `harness-setup.mjs` detect existing environments (`install-detect.mjs`, `installation/profiles.mjs`), evaluate or seed prepared store bundles via `install-store.mjs` (`isPreparedStore`, `writeStoreMarker`, `applyStorePlan`), acquire `deployment.lock` via `installation/journal.mjs`, parse and preflight configs via `installation/config.mjs`, mutate target harness configs via `installation/adapters.mjs` and `installation/hermes-policy.mjs`, record rollback journals, and validate capabilities (`installation/capabilities.mjs`).
3. **Drift Synchronization & Snapshotting**: `sync.mjs` and `sync-prune.mjs` evaluate worktree boundaries via `worktree-snapshot.mjs` and managed blocks via `installation/config.mjs`, diffing file hashes between repo sources and installed harnesses to deploy, promote, or prune drift.
4. **Task Coordination & Workflow SDD (`workflow/`, `workflow-core.mjs`)**: `workflow.mjs` orchestrates CLI workflow turns across tiers (T0–T3), delegating persistence, file locking (`withStateLock`), metric logging, and artifact validation to `workflow-core.mjs` (`state.json`, `budgets.json`, `metrics.jsonl`). `workflow-ci.mjs` coordinates CI checks and task settlement (`checkQualityGates`, `cmdSettle`). Subagents claim tasks via `workflow/claims.mjs`, isolate execution worktrees in `workflow/workspaces.mjs`, validate plans (`plan-check.mjs`), monitor trajectories (`trajectory.mjs`), respect tripwires (`tripwire.mjs`), append local gate telemetry via `gate-counter.mjs` (`recordGate`), and record tamper-evident receipts (`journal.mjs`). Core state lifecycle transitions are deterministically verified by `lifecycle-evals.mjs` (`runLifecycleEvals`).
5. **Quality Gating & Static Analysis (`quality/`)**: `quality.mjs` dispatches to `quality/engine.mjs`, discovering technology stacks from `quality/stacks.json`, running linters and compilers, normalizing outputs via `quality/parsers.mjs`, validating cognitive complexity thresholds, enforcing ratchet baselines, checking color contrast (`contrast-check.mjs`), enforcing size ceilings (`code-size.mjs`), and auditing technical debt markers (`debt-ledger.mjs`).
6. **Controlled Review Arbitration (`review/`)**: `auto-review.mjs` coordinates model selection via `oracle-model.mjs`, authorizes tool access via `review/gatekeeper.mjs`, delegates execution to `review/http-runtime.mjs` within financial constraints (`review/budget.mjs`), performs in-process inspection (`review/native-tools.mjs`), projects cryptographic receipts (`review/http-evidence.mjs`, `review/evidence.mjs`), and arbitrates verdicts (`review/arbitrate.mjs`).
7. **Diagnostics, Manifest Diagnosis & Skill Auditing**: `doctor.mjs` runs diagnostic suites, delegating checks to `doctor-checks.mjs` and `doctor-shared.mjs`, while `doctor-lite.mjs` provides turn preflights and `worktree-doctor.mjs` audits worktrees. `dependency-doctor.mjs` parses manifests (`requirements.txt`, `pyproject.toml`, `package.json`) offline to identify stdlib shadowing and obsolete backports. `skill-security.mjs` and `skills-doctor.mjs` audit skill frontmatter, security posture, and trigger fixtures.
8. **Package Certification & Release**: `publish-release.mjs`, `certify-package.mjs`, and `npm-smoke.mjs` / `npm-smoke-harness.mjs` pack archives (`package-archive.mjs`), execute matrix verifications across isolated test roots, check npm registry status (`self-update.mjs`), and publish packages.
9. **Benchmark, Candidate Optimization & Replay Evaluation**: `run-skill-benefit-eval.mjs`, `benchmark.mjs`, `benchmark-run.mjs`, and `bench-optimizer.mjs` execute evaluations using `bench-session-runner.ts` or replayed cassettes (`lm-replay.mjs`, `replay.mjs`), enforcing tariffs (`bench-budget.mjs`), scoring session outcomes (`bench-results.mjs`), generating single AST mutations (`generateOneMutation`), and aggregating metrics (`bench-analytics.mjs`, `quality-evidence.mjs`).
10. **Changed-Scope CI Gates**: `changed-scope.mjs` resolves the base ref and diff once; `mutation-changed.mjs` and `coverage-changed.mjs` each match changed files to a suite (`findMatchingSuite`), run the per-file gate, and aggregate exit status. Empty diff short-circuits to exit 0 before any work.
11. **Route Resolution & Delivery Reporting**: `model-router.mjs` loads `models.yml`, classifies entries (`classifyModel`), and resolves a category by walking the chain, throwing `ModelStopQuestionError` / `MODEL_STOP_QUESTION` when nothing available fits rather than silently substituting. `cfr-report.mjs` parses `git log` and `lead-time.mjs` parses `.workflow/events.jsonl`; both print zeros on missing input and exit 0.
12. **Cockpit Observability**: `dashboard.mjs` initializes the local HTTP daemon on loopback `127.0.0.1`, gathers system and repository metrics via `dashboard-collectors.mjs` (validating Host headers with `isAllowedHost`) and `dashboard-needed.mjs`, serves routes and AST architecture drill-downs via `arch-drill.mjs` (`collectArchDrill`, `collectSymbolInventory`), and streams interactive UI layouts (`dashboard-ui.mjs`, `dashboard-shell-client.mjs`, `dashboard-sketch.mjs`, `dashboard-arch-client.mjs`).

## Integration Points
- **CLI / Host Harness**: Invoked by `install.ps1`/`install.sh`, `verify.ps1`/`verify.sh`, `tools/audit.ps1`/`tools/audit.sh`, `tools/sync.ps1`/`tools/sync.sh`, `bin/nullform.mjs`, `omp` CLI, and `openspec`; configures and mutates 8 agent harness environments (`claude`, `codex`, `opencode`, `cursor`, `omp`, `openclaw`, `hermes`, `openhuman`).
- **Submodule Domains**:
  - `tools/installation/`: adapter configuration, host profile detection, YAML/JSON preservation, journaled locking (`deployment.lock`), prepared-store planning (`install-store.mjs`), and restore mechanisms.
  - `tools/review/`: controlled review execution, financial ledgers, gatekeeping, in-process tools, HTTP completions, and historical evidence validation.
  - `tools/quality/`: multi-stack analysis definitions (`quality/stacks.json`), engine execution (`quality/engine.mjs`), and AST/SARIF report parsers (`quality/parsers.mjs`).
  - `tools/workflow/`: durable concurrent task leasing (`workflow/claims.mjs`), lifecycle evaluation (`lifecycle-evals.mjs`), and execution workspace/worktree isolation (`workflow/workspaces.mjs`).
- **Agent Extensions & Review Sandboxes**: Interfaces with `agent/extensions/nullform-jev.ts` via JEV policies (`jev-evidence.mjs`, `jev-assist.mjs`) and review sandboxes via `review/native-tools.mjs`.
- **Shared Data Contracts & State Files**: `.workflow/state.json`, `.workflow/events.jsonl`, `.workflow/metrics.jsonl`, `.workflow/budgets.json`, `.workflow/gate-counts.jsonl`, `.store-marker`, `.codemap/state.json`, `tools/sync-manifest.json`, `skills-lock.json`, `agent/models.yml.example`, `bench/runs/spend-ledger.json`, `core/quality-evidence.summary.json`, and `tools/quality/stacks.json`.
- **System Boundaries & Runtimes**: Spawns Node.js, Bun (for benchmark sessions), Python (`tools/session_cost.py`), npm, git (via safe `execFileSync` argv arrays in `domain-context.mjs`), PowerShell, bash, and loopback HTTP server on `127.0.0.1` (`dashboard.mjs`, `replay.mjs`).
- **Module Cycles (Known & Preserved)**: Bidirectional and circular dependencies maintained for compatibility: `bench-analytics.mjs` <-> `bench-smoke.mjs` <-> `benchmark.mjs` (benchmark run/results/analytics triangle); `skill-audit.mjs` <-> `skill-security.mjs` (skill frontmatter parser and security evaluator).
