# tools/

## Responsibility
CLI Toolchain, Governance Facade, and Diagnostic Harness for the OMP workflow. Provides drift synchronization, tier-based SDD workflow enforcement (T0–T3), subagent coordination and task leasing, cross-harness adapter configuration, transactional packaging and release certification, benchmark and replay evaluation, cognitive complexity and quality gating, and real-time observability dashboards for agent operations. Houses non-codemapped submodules for cross-harness configuration mutators (`tools/installation/`), controlled review arbitration (`tools/review/`), multi-stack quality analyzers (`tools/quality/`), and concurrent subagent coordination (`tools/workflow/`).

## Design Patterns
- **CLI Toolchain / Dispatcher Facade**: Subcommand routers (`workflow.mjs`, `workflow-ci.mjs`, `sync.mjs`, `codemap.mjs`, `jev-control.mjs`, `worktree-doctor.mjs`) coordinating child processes, git status queries, and repository state.
- **Modular Observer & Cockpit Server (Dashboard Split)**: `dashboard.mjs` serves as HTTP daemon and lifecycle coordinator, delegating to specialized modules: `dashboard-routes.mjs` for route dispatch (`/api/state`, `/api/diff`, `/api/arch`, `/api/arch/drill`, `/api/arch/svg`); `dashboard-collectors.mjs` for protocol versioning, git metrics, and host security; `dashboard-needed.mjs` for human action gap analysis; `dashboard-ui.mjs` for HTML cockpit rendering; `dashboard-shell-client.mjs` for CSS, client JS, and RU/EN i18n dictionaries; `dashboard-sketch.mjs` for procedural Excalidraw-like canvas geometries; and `dashboard-arch-client.mjs` along with `arch-drill.mjs` for AST symbol drill-down.
- **Layered Diagnostic Probe (Doctor Split)**: Diagnostic ecosystem separated into `doctor.mjs` (CLI driver, provider reachability, formatted terminal output), `doctor-checks.mjs` (16 isolated environment and wiring health checks), `doctor-lite.mjs` (fast lightweight preflight probe for workflow turns), and `doctor-shared.mjs` (`CORE_TOOLS`, `REQUIRED_ROLES`, path normalization, BOM stripping); supplemented by `worktree-doctor.mjs` (worktree pruning), `skills-doctor.mjs` (skill registry integrity), `cache-doctor.mjs` (cause code analysis), and `cache-policy.mjs`.
- **Strategy & Verification Profiles**: Pluggable verification strategies split between `verify.mjs` (dispatcher), `verify-profile.mjs` (deep verification suite), `audit-profile.mjs` (auditing passes), and `verify-shared.mjs` (shared execution helpers), alongside tier-specific SDD workflow rules (`workflow.mjs`, `tripwire.mjs`) and subagent return contract enforcement (`return-contract.mjs`).
- **Subagent Task Coordination & Workspaces (`workflow/`)**: `workflow/claims.mjs` manages lease-locked task claims (`claimTask`, `releaseTask`) and context packets across parallel subagents; `workflow/workspaces.mjs` isolates execution workspaces and worktree lifecycles.
- **Controlled Review & Financial Authority (`review/`)**: `tools/review/` enforces bounded review execution: `review/budget.mjs` acts as the single financial authority tracking token ledgers; `review/gatekeeper.mjs` intercepts dangerous tool invocations; `review/http-runtime.mjs` and `review/http-child.mjs` run sandboxed direct HTTP completions; `review/native-tools.mjs` provides in-process product inspections (`inspectProduct`, `executeProduct`, `readProductPage`); `review/evidence.mjs` and `review/http-evidence.mjs` generate cryptographic receipts; `review/evidence-history.mjs` validates git lineage; and `review/arbitrate.mjs` arbitrates verdicts and computes F1 scores.
- **Adapter & Transactional Packaging (`installation/`)**: `tools/installation/` manages cross-harness lifecycle: `installation/adapters.mjs` applies harness-specific configurations across 8 target engines; `installation/capabilities.mjs` detects host features and version parity; `installation/config.mjs` injects managed comment blocks (`MANAGED_START`/`MANAGED_END`); `installation/journal.mjs` coordinates rollback-safe deployments with exclusive lock `deployment.lock`; `installation/state.mjs` tracks SemVer identity; `installation/profiles.mjs` resolves host homes; `installation/restore.mjs` handles rollbacks; and `installation/hermes-policy.mjs` mutates YAML policies.
- **Multi-Stack Quality & Gatekeeper (`quality/`)**: `quality.mjs` enforces cognitive complexity limits and analyzer baselines using `quality/stacks.json` and normalized report translators in `quality/parsers.mjs` (ESLint, Pylint, Cargo, SARIF); paired with `contrast-check.mjs` (WCAG 2.x), `coverage-check.mjs` (spec-brief coverage), `code-size.mjs`, `mutation-test.mjs`, and `debt-ledger.mjs` (`# ponytail:` tracking).
- **Benchmark Harness & Replay Sandbox**: Empirical LLM evaluation suite (`benchmark.mjs`, `benchmark-run.mjs`, `bench-smoke.mjs`, `bench-analytics.mjs`, `bench-budget.mjs`, `bench-results.mjs`, `bench-session-runner.ts`, `lm-replay.mjs`, `replay.mjs`, `run-skill-benefit-eval.mjs`, `orchestrator-evals.mjs`) executing native SDK runs under Bun with deterministic tariff tracking and cassette replay.
- **Judicial Evidence Verification (JEV) Suite**: `jev-control.mjs`, `jev-assist.mjs`, `jev-evaluate.mjs`, `jev-evaluation-cases.mjs`, and `jev-evidence.mjs` automate paired empirical evaluation and policy validation for agent skill triggers.

## Data & Control Flow
1. **Entry & Subcommand Routing**: CLI scripts (`workflow.mjs`, `verify.mjs`, `sync.mjs`, `doctor.mjs`, `dashboard.mjs`, `bin/nullform.mjs`) parse args, validate runtime environment (`preflight-env.mjs`, `sanitize-text.mjs`), and resolve configurations (`agent/models.yml.example`, `sync-manifest.json`, `skills-lock.json`).
2. **Harness Setup & Transactional Mutation (`installation/`)**: `install-harness.mjs` and `harness-setup.mjs` detect existing environments (`install-detect.mjs`, `installation/profiles.mjs`), acquire `deployment.lock` via `installation/journal.mjs`, parse and preflight configs via `installation/config.mjs`, mutate target harness configs via `installation/adapters.mjs` and `installation/hermes-policy.mjs`, record rollback journals, and validate capabilities (`installation/capabilities.mjs`).
3. **Drift Synchronization & Snapshotting**: `sync.mjs` and `sync-prune.mjs` evaluate worktree boundaries via `worktree-snapshot.mjs` and managed blocks via `installation/config.mjs`, diffing file hashes between repo sources and installed harnesses to deploy, promote, or prune drift.
4. **Task Coordination & Workflow SDD (`workflow/`)**: `workflow.mjs` and `workflow-ci.mjs` enforce tier ladders (T0–T3), parse requirements (`requirements.mjs`), coordinate subagent task leases (`workflow/claims.mjs`), provision isolated execution worktrees (`workflow/workspaces.mjs`), validate execution plans (`plan-check.mjs`), monitor subagent trajectories (`trajectory.mjs`), enforce token tripwires (`tripwire.mjs`), and record tamper-evident receipts (`capsule.mjs`, `journal.mjs`).
5. **Quality Gating & Static Analysis (`quality/`)**: `quality.mjs` discovers technology stacks from `quality/stacks.json`, runs linters/compilers, normalizes outputs via `quality/parsers.mjs`, validates cognitive complexity thresholds, checks color contrast (`contrast-check.mjs`), verifies spec coverage (`coverage-check.mjs`), enforces size ceilings (`code-size.mjs`), and audits technical debt markers (`debt-ledger.mjs`).
6. **Controlled Review Arbitration (`review/`)**: `auto-review.mjs` coordinates model selection via `oracle-model.mjs`, authorizes tool access via `review/gatekeeper.mjs`, delegates execution to `review/http-runtime.mjs` within financial constraints (`review/budget.mjs`), performs in-process inspection (`review/native-tools.mjs`), projects cryptographic receipts (`review/http-evidence.mjs`, `review/evidence.mjs`), and arbitrates verdicts (`review/arbitrate.mjs`).
7. **Diagnostics & Health Auditing**: `doctor.mjs` runs diagnostic suites, delegating checks to `doctor-checks.mjs` and `doctor-shared.mjs`, while `doctor-lite.mjs` provides sub-millisecond turn preflights, `worktree-doctor.mjs` audits git worktrees, and `skills-doctor.mjs` validates skill frontmatters.
8. **Package Certification & Release**: `publish-release.mjs`, `certify-package.mjs`, and `npm-smoke.mjs` / `npm-smoke-harness.mjs` pack archives (`package-archive.mjs`), execute matrix verifications across isolated test roots, check npm registry status (`self-update.mjs`), and publish packages.
9. **Benchmark & Replay Evaluation**: `run-skill-benefit-eval.mjs`, `benchmark.mjs`, and `benchmark-run.mjs` execute evaluations using `bench-session-runner.ts` or replayed cassettes (`lm-replay.mjs`), enforcing tariffs (`bench-budget.mjs`), scoring session outcomes (`bench-results.mjs`), and aggregating metrics (`bench-analytics.mjs`, `quality-evidence.mjs`).
10. **Cockpit Observability**: `dashboard.mjs` initializes the local HTTP daemon, gathers system and repository metrics via `dashboard-collectors.mjs` and `dashboard-needed.mjs`, serves routes and AST architecture drill-downs via `dashboard-routes.mjs` and `arch-drill.mjs`, and streams interactive UI layouts (`dashboard-ui.mjs`, `dashboard-shell-client.mjs`, `dashboard-sketch.mjs`, `dashboard-arch-client.mjs`).

## Integration Points
- **CLI / Host Harness**: Invoked by `install.ps1`/`install.sh`, `verify.ps1`/`verify.sh`, `tools/audit.ps1`/`tools/audit.sh`, `tools/sync.ps1`/`tools/sync.sh`, `bin/nullform.mjs`, `omp` CLI, and `openspec`; configures and mutates 8 agent harness environments (`claude`, `codex`, `opencode`, `cursor`, `omp`, `openclaw`, `hermes`, `openhuman`).
- **Submodule Domains**:
  - `tools/installation/`: adapter configuration, host profile detection, YAML/JSON preservation, journaled locking (`deployment.lock`), and restore mechanisms.
  - `tools/review/`: controlled review execution, financial ledgers, gatekeeping, in-process tools, HTTP completions, and historical evidence validation.
  - `tools/quality/`: multi-stack analysis definitions (`quality/stacks.json`) and AST/SARIF report parsers (`quality/parsers.mjs`).
  - `tools/workflow/`: durable concurrent task leasing (`workflow/claims.mjs`) and execution workspace/worktree isolation (`workflow/workspaces.mjs`).
- **Agent Extensions & Review Sandboxes**: Interfaces with `agent/extensions/nullform-jev.ts` via JEV policies (`jev-evidence.mjs`, `jev-assist.mjs`) and review sandboxes via `review/native-tools.mjs`.
- **Shared Data Contracts & State Files**: `.workflow/state.json`, `.workflow/events.jsonl`, `.workflow/metrics.jsonl`, `.codemap/state.json`, `tools/sync-manifest.json`, `skills-lock.json`, `agent/models.yml.example`, `bench/runs/spend-ledger.json`, `core/quality-evidence.summary.json`, and `tools/quality/stacks.json`.
- **System Boundaries & Runtimes**: Spawns Node.js, Bun (for benchmark sessions), Python (`tools/session_cost.py`), npm, git, PowerShell, bash, and loopback HTTP server on localhost.
