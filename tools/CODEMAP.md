# tools/

## Responsibility
CLI Toolchain, Governance Facade, and Diagnostic Harness for the OMP workflow. Provides drift synchronization, tier-based SDD workflow enforcement, cross-harness adapter configuration, transactional packaging and release certification, benchmark and replay evaluation, and observability dashboards for agent operations.

## Design Patterns
- **CLI Toolchain / Dispatcher Facade**: Subcommand routers (`workflow.mjs`, `sync.mjs`, `codemap.mjs`, `jev-control.mjs`) exposing high-level commands over filesystem operations and child process spawning.
- **Strategy**: Pluggable verification and gate profiles (`verify` vs `audit` in `verify.mjs`), tier enforcement strategies (T0–T3 in `workflow.mjs`), return contract validators (`return-contract.mjs`), and sync reconciliation modes (`--check`, `--deploy`, `--promote`, `--prune` in `sync.mjs`, `sync-prune.mjs`).
- **Registry / Manifest-Driven Configuration**: File mapping tables (`sync-manifest.json`), tool validation lists (`CORE_TOOLS` in `doctor.mjs`), requirement hierarchies (`REQUIREMENTS` in `workflow.mjs`), and harness enumeration tables (`HARNESS_CHOICES` in `installation/state.mjs`).
- **Doctor / Diagnostic Probe**: Independent health check runners (`doctor.mjs`, `cache-doctor.mjs`, `skills-doctor.mjs`, `cache-policy.mjs`) returning normalized status envelopes (`pass`, `warn`, `fail`, `skip`), supplemented by static skill validation (`skill-audit.mjs` in `prompt-lint.mjs`) and session inefficiency heuristics (`session-retro.mjs`).
- **Observer / State Server**: `dashboard.mjs` aggregates repository scanners, workflow artifacts, and git state into an HTTP server (`/api/state`, `/api/diff`) and browser cockpit.
- **Adapter / Portability Bridge**: Cross-harness configuration mutators and capability detectors (`installation/adapters.mjs`, `installation/capabilities.mjs`, `installation/config.mjs`, `install-harness.mjs`) configuring 8 supported agent harnesses through managed block injection and format-preserving parsers (`yaml`, `json5`, `jsonc-parser`).
- **Transaction Journal / Lock Manager**: Rollback-safe deployment engine (`installation/journal.mjs`) providing PID-validated exclusive file locks (`deployment.lock`), atomic staging, and journaled state rollbacks during installs and updates.
- **Pipeline / Release Certification Gate**: Multi-stage packaging, verification, and distribution pipeline (`package-archive.mjs`, `certify-package.mjs`, `npm-smoke.mjs`, `publish-release.mjs`) enforcing clean worktrees, matrix compatibility (`REQUIRED_MATRIX_CELLS`), SemVer state tracking (`installation/state.mjs`), and global package self-updates (`self-update.mjs`).
- **Evidence & Provenance Attestation**: Cryptographic integrity and review attestation engines (`quality-evidence.mjs`, `review/evidence.mjs`, `review/native-tools.mjs`, `worktree-snapshot.mjs`) validating git worktrees, Stage-A test locks, Oracle verdict parsing, and bounded in-process product inspection.
- **Benchmark Harness / Replay Sandbox**: Empirical LLM evaluation and budget control harness (`bench-budget.mjs`, `bench-results.mjs`, `bench-session-runner.ts`, `lm-replay.mjs`, `run-skill-benefit-eval.mjs`, `benchmark.mjs`, `jev-evaluate.mjs`) executing native SDK runs under Bun, enforcing fixed tariffs and spend ledgers, and replaying zero-cost redacted cassettes.

## Data & Control Flow
1. **Entry & Argument Dispatch**: CLI entry points parse arguments, resolve runtime roots (`harnessRoot`, `repoRoot`, `agentDir`), and read configs (`models.yml`, `sync-manifest.json`, `.workflow/state.json`).
2. **Harness Installation & Mutation**: `install-harness.mjs` acquires `deployment.lock`, preflights configs (`installation/config.mjs`) and path confinement (`worktree-snapshot.mjs`), mutates target harness assets (`installation/adapters.mjs`), records journaled operations (`installation/journal.mjs`), writes `.nullform/installation-state.json`, and rolls back on failure.
3. **Sync Reconciliation**: `sync.mjs` and `sync-prune.mjs` evaluate path boundaries (`worktree-snapshot.mjs`) and managed blocks (`installation/config.mjs`), computing file hashes between repo sources and installed harnesses to deploy, promote, or prune drift.
4. **Workflow SDD & CI Gate**: `workflow.mjs` validates change deliverables against tier ladders (T0–T3), scans git status and path boundaries (`worktree-snapshot.mjs`), validates Oracle ACCEPT/REJECT verdicts and review receipts (`review/evidence.mjs`), parses transcript metrics (`session-retro.mjs`), and enforces commit ancestry.
5. **Verification & Diagnostics**: `verify.mjs` and `doctor.mjs` execute sub-tool suites (`prompt-lint.mjs`, `skill-audit.mjs`), probing version alignment and harness capability readiness (`installation/capabilities.mjs`) and checking update availability (`self-update.mjs`).
6. **Package Certification & Release**: `publish-release.mjs`, `certify-package.mjs`, and `npm-smoke.mjs` pack archives (`package-archive.mjs`), verify multi-platform matrix cells in isolated temporary roots, validate review evidence, and publish releases to npm.
7. **Benchmarking & Replay Evaluation**: `run-skill-benefit-eval.mjs` and `benchmark.mjs` execute tasks via `bench-session-runner.ts` or replayed cassettes (`lm-replay.mjs`), enforcing tariff and spend constraints (`bench-budget.mjs`), parsing session outcomes (`bench-results.mjs`), and exporting summaries (`quality-evidence.mjs`).
8. **Cockpit Observability**: `dashboard.mjs` ingests scan results (`debt-ledger.mjs`, git status) and serves real-time cockpit state via HTTP endpoints.

## Integration Points
- **CLI / Host Harness**: Invoked by `install.ps1`/`install.sh`, `audit.ps1`/`audit.sh`, `bin/nullform.mjs`, `omp` CLI, and `openspec`; manages 8 target harnesses (`claude`, `codex`, `opencode`, `cursor`, `omp`, `openclaw`, `hermes`, `openhuman`).
- **Agent Extensions & Review Sandboxes**: Interfaces with `agent/extensions/nullform-jev.ts` via JEV policies (`jev-policy.json`, `jev-evidence.mjs`) and review subshells via `review/native-tools.mjs`.
- **Shared Data Contracts & State Files**: `.workflow/state.json`, `.workflow/budgets.json`, `.workflow/session-retro.json`, `.codemap/state.json`, `sync-manifest.json`, `agent/models.yml`, `.nullform/installation-state.json`, `.nullform/deployment-journal.json`, `review-evidence.json`, `bench/runs/spend-ledger.json`, and `core/quality-evidence.summary.json`.
- **System Boundaries & Runtimes**: Spawns Node, npm, git, PowerShell, bash, and HTTP server on loopback localhost.
