# Benchmark: Синтетический прогон T2-воркфлоу (universal-1)

Этот документ описывает методику, контрольные цифры и процедуру воспроизведения синтетического бенчмарка контрольного T2-прогона (`tools/benchmark-run.mjs`, требование R07).

## 1. Методика

### 1.1. Модель синтетического прогона
Бенчмарк моделирует полный сквозной цикл выполнения задачи яруса **T2** (мульти-модульное изменение с архитектурным контрактом) четырьмя ключевыми ролями воркфлоу:
1. **@orchestrator** (Волна 0): анализ брифа, определение яруса (T2), декомпозиция на волны и тикеты.
2. **@explorer** (Волна 1): исследование кодовой базы, AST-разведка, построение карты модулей и графа зависимостей.
3. **@fixer** (Волна 2–3): реализация TDD-цикла, правка логики, написание и прогон модульных/интеграционных тестов.
4. **@oracle** (Волна 4): слепая верификация по брифу, проверка контрактов и вынесение вердикта приёмки.

### 1.2. Метрика нормированной стоимости (`normalizedCost`)
Для независимости от нестабильных цен провайдеров и валютных курсов используется каноническая формула из `tools/cost-snapshot.mjs`:
$$\text{Units} = 5 \cdot \text{outputTokens} + 1.25 \cdot \text{cacheWriteTokens} + 0.1 \cdot \text{cacheReadTokens}$$

Флаг `cacheChurn` (неэффективная перезапись кэша) выставляется, если отношение записи к чтению превышает 10%:
$$\text{cacheChurn} = (\text{cacheWrite} / \text{cacheRead}) > 0.10$$

### 1.3. Принципы детерминизма
- **0 внешних сетевых вызовов**: прогон полностью локален и детерминирован.
- **0 платных API**: синтетическая фикстура воспроизводит реальные паттерны вызовов без затрат.
- **Идемпотентность**: повторные запуски дают строго идентичные результаты (`total`, `roles`, `tests`, `ms`).

## 3. Как повторить

### 3.1. Запуск бенчмарка через CLI
Запуск встроенного контрольного бенчмарка:
```bash
node tools/benchmark-run.mjs
```

Запуск в машинно-читаемом формате JSON:
```bash
node tools/benchmark-run.mjs --json
```

Запуск на пользовательской фикстуре (директория или файл):
```bash
node tools/benchmark-run.mjs --fixture path/to/fixture --json
```

### 3.2. Автоматические тесты
Проверка детерминизма и контракта бенчмарка:
```bash
node --test tools/tests/u-waves.test.mjs
```
Тест валидирует:
1. Равенство результатов двух независимых прогонов (`r1.total === r2.total`).
2. Точность расчёта формулы `normalizedCost` по ролям.
3. Отсутствие платных и сетевых вызовов.
