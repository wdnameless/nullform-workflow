# Good Design Examples (`docs/examples/good/`)

This directory contains short, annotated positive references for the project.

## Convention & Guidelines
- **Purpose**: Ground the visual direction in concrete samples. Examples demonstrate what to steal (typography hierarchy, card layout, spacing density, micro-interactions, color balance).
- **Format**: Short annotated notes, markdown files, image files, or URL references. Each entry should clearly state:
  1. What this sample is (e.g. `hero-split-desktop.png` or `dashboard-table.md`).
  2. Exactly what to steal / emulate from it.
- **Quantity limit**: Keep it bounded: **5 to 15 items maximum**. Curate strictly; do not dump uncurated galleries.
- **Storage**: No heavy binaries required. URLs, lightweight SVG, markdown annotations, or compressed screenshots are preferred.
- **Precedence**: When an example contradicts the approved Reference Lock in `docs/DESIGN.md`, the **Reference Lock always wins**. Any conflict must be explicitly reported.
