## Purpose / Big Picture

A user installs nullform-workflow through npm, selects one of the eight existing AI coding clients, runs core workflow gates through the public nullform CLI, and updates without Git or hidden dependencies on a different client. Their existing instructions, configuration and edited assets survive reapplication or failure. The release is certified against the exact package archive on Windows, Linux and macOS. An evidence view explains what was actually measured rather than treating test counts as proof of AI development-quality improvement.

The user selected public npm release, no additional paid A/B experiments, permission to change project-owned workflow prompts, and release without unproven claims. Personal settings, keys and global machine instructions remain untouched. No new paid model comparison is run; ordinary implementation/review work is separate from that experiment decision.

## Idempotence and Recovery

Writers use isolated worktrees and exclusive files. Retry/reapply preserves human bytes. Recovery restores only validated owned destinations and refuses tampered paths or uncertain concurrency. State/journal creation and cleanup leave no stale success marker. Remove temporary probes after evidence. Do not reset histories/ledgers. Published versions are immutable: verify an existing version or choose a new version, never overwrite it.
