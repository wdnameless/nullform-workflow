## The two rejections, and what each produced

1. **`MergeGate` REJECT** → commit `5e0adf6`:
   - `tools/sync.ps1` had a literal `D:\ohmypi\...` path — the exact defect class this audit
     removes, fixed in `sync.sh` and missed in its PowerShell twin.
   - prune's suffix deny-list reported OMP's own runtime state (`agent/kimi-device-id`,
     `agent/last-changelog-version`) as deletable orphans; `--prune --confirm` would have
     destroyed it, and `doctor.mjs` reported the same false orphans.
2. **`MergeGate2` REJECT** → commit `209b82f`:
   - the allow-list from the first fix ran *after* the deny-list, making it unreachable for
     `.yml`/`.json`/`.md` — precisely the extensions the repo ships (`templates/ci/*.yml`,
     `agent/plugins.json`). A planted `templates/ci/other.yml` was silently never reported.
     The deny-list is now removed entirely.
   - one failing row (`skills/x/SKILL.md` must be reported) was **adjudicated as a false
     premise supplied by the author's own prompt**: `skills/` is documented out of the prune
     walk, the pre-existing test asserts the exclusion, and skills are covered by
     `skills-doctor` parity instead. Recorded in `oracle.md` rather than silently dropped.
