# Фоновые задачи

Всё, что происходит не сразу: очереди, обработка файлов, отложенные письма.

## Промпт

```
Найди все фоновые задачи и очереди в проекте: где ставятся, где выполняются,
что происходит при отказе. Покажи списком.

Напиши тесты на самую важную:
1. обычный ход — задача выполнилась, результат в базе;
2. внешний сервис упал — запись ушла в состояние «ошибка» с понятным текстом,
   а НЕ зависла в состоянии «обрабатывается»;
3. то же событие пришло дважды — результат не задвоился.

Никаких пауз на фиксированное время: используй встроенное ожидание результата.
Покажи вывод и время прогона.
```
