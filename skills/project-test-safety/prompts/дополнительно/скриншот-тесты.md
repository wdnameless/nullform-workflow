# Скриншот-тесты

Единственный уровень, который видит вёрстку. И почти никому из вас он сейчас не нужен.

## Промпт

```
Сначала оцени честно и ответь текстом: нужны ли этому проекту скриншот-тесты?
Критерии — есть ли дизайн-система, правит ли вёрстку больше одного человека,
были ли уже баги с разъехавшейся вёрсткой. Если нет — так и скажи, и предложи
вместо этого зафиксировать структуру страницы текстом.

Если нужны, настрой по минимуму:
- одна-две страницы, не больше;
- закрой масками всё динамическое: даты, счётчики, аватарки, суммы;
- зафиксируй размер окна;
- эталоны снимай в том же окружении, где они будут сравниваться, иначе
  из-за шрифтов всё будет падать;
- на сервере запрети молчаливое создание недостающих эталонов.

И отдельным правилом: эталоны обновляет человек, глядя на разницу. Не ты.
```
