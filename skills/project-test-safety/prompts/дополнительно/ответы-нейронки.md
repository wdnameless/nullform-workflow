# Нейронка внутри продукта

Если модель отвечает пользователю, обычные тесты не работают: ответ каждый раз разный.

## Промпт

```
Найди все места, где продукт обращается к языковой модели, и покажи,
что делается с ответом.

Сделай две вещи:

1. Переведи ответ на строгую схему на уровне провайдера и добавь проверку
   структуры на нашей стороне. Напиши тесты: правильный ответ проходит,
   ответ с лишним или отсутствующим полем — падает.

2. Добавь проверку привязки к входным данным: если модель приводит цитату
   или ссылку на фрагмент, этот фрагмент обязан находиться во входном тексте.
   Тест на выдуманную цитату должен падать.

Настоящую модель в тестах не зови — используй заглушку. Любое необъявленное
обращение к модели в тестовом режиме должно ронять тест.
```
