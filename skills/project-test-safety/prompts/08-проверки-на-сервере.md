# 8 · Проверки на сервере

```
Сначала прочитай `тесты/контекст.md` — там результат диагностики: стек, команды,
база, главные действия и что нельзя ломать. Если файла нет — скажи мне об этом
и разберись сам, но короче.

Добавь прогон команды `check` и браузерных тестов на стороне репозитория:
на каждую отправку кода и на каждый запрос на изменения.
Версия среды — та же, что локально.
Покажи конфиг и ссылку на прогон.
```

**Дальше руками, промптом не делается:**
настройки репозитория → правила ветки → требовать успешное прохождение проверок.

**Что должно получиться:** красный запрос на изменения с заблокированной кнопкой Merge.

**Оговорка:** на бесплатном тарифе GitHub защита ветки работает только в публичных
репозиториях.
