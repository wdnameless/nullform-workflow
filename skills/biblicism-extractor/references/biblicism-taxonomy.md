# Biblicism taxonomy

## Definition

Библеизм — единица языка, обладающая определенным значением, возникшая на базе текста Библии или библейского сюжета.

## Structural levels

- Лексические единицы: библеизмы-слова (антропонимы, топонимы, библейские реалии)
- Библейские фразеологизмы: библеизмы-словосочетания
- Библеизмы-междометия
- Библейские цитаты
- Библеизмы-пословицы: библеизмы-предложения

## Search rules

1. Use the dictionary as a whitelist and a verification aid.
2. Only keep matches that exist in the source text verbatim.
3. If a candidate is semantically similar but not exact, label it as doubtful or omit it.
4. Keep source location for every item.
5. Preserve the example table layout exactly when generating the final DOCX.
