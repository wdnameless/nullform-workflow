# Interfaces: npm-workflow-cli

## Owners

- PackageCli: package.json, VERSION, LICENSE if needed, bin/nullform.mjs, tools/self-update.mjs, tools/tests/self-update.test.mjs, tools/tests/nullform-cli.test.mjs. No installer/doctor/docs edits.
- HarnessAdapters: tools/install-harness.mjs, tools/doctor.mjs, required focused install-config helper if extraction earns its place, existing install/doctor tests and affected contract-only tests. No package/CLI/update/docs edits.
- PackageProof: tools/npm-smoke.mjs, tools/tests/npm-distribution.test.mjs, local registry helper under tools/tests if required, README.md, CONTEXT.md. No other code ownership. Tests/build/lint run only by parent after integration.

## Shared contracts

- Package: name nullform-workflow, version 1.1.0, type module, bin nullform -> bin/nullform.mjs, Node >=18.19.0. Pinned yaml 2.9.1, json5 2.2.3 and jsonc-parser 3.3.1 are justified native config parsers; normal npm dependencies, not bundled developer module trees. No lifecycle script modifies home. Explicit runtime files allowlist preserves third-party licenses and excludes private/generated/history/source test data.
- CLI: init, doctor, update, --help/-h and --version. init supports --harness <one of 8>, --root, --project-root, --user-home, --yes, --dry-run, --json. Interactive menu uses node readline; non-TTY requires explicit or saved selection and --yes for writes. Dry-run never writes state or target.
- Installer: retain installHarness(options) export; harness/root/projectRoot/userHome/dryRun are authoritative. CLI passes prior managedFiles if used. Return plan.harness/root/projectRoot/userHome/filesToCopy/adapters/managedFiles. Source-verified native paths are authoritative: OpenCode global .config/opencode, Cursor project rules, OpenClaw JSON5 agents.entries, Hermes YAML without fictitious profiles, OpenHuman native AGENTS/physical skills. Preflight syntax, structure and managed markers before any writes. Deliver only required parser runtimes to stable tools/node_modules so copied tools resolve dependencies; never copy the whole developer module tree.
- State: <userHome>/.nullform/installation.json, schemaVersion:1, harness:string, root:absolute runtime root, optional projectRoot:absolute active project, userHome:absolute, version:semver, optional managedFiles map. CLI is sole state writer; save verified successful installation identity, not a structural doctor failure. No keys/config contents stored in state. Validation fails closed. Cursor fresh CLI defaults projectRoot to current project; update reuses the saved project rather than its own cwd.
- Doctor: retain synchronous runDoctor(options), targetHarness defaults omp for legacy callers; explicit selected installation routes native checks and reports targetHarness/projectRoot. Return {ok,checks,summary,...}. Missing host/runtime/plugin/provider prerequisite is honest SETUP/warn for selected mode, not operational readiness. Malformed native config or missing managed integration is FAIL. OMP-only checks truly omitted for other hosts; never hide failures behind a universal skip flag. Parser diagnostics expose safe code/location, not secret-bearing source fragments.
- Update: retain checkRelease(options) shape {status:clean|drift|setup,ok,current,latest,detail,...}; npm version metadata, no Git/GitHub-tag path. Native npm registry/prefix configuration honored. Execute real global npm install, then NEW installed bin re-init/check with saved harness/runtime/project/home. No stale binary fallback or untrusted shell interpolation. Failed npm/reapply/doctor never claims success or replaces prior verified identity; later retry cannot mistake a merely advanced VERSION file for verified deployment.
- npm-smoke: node tools/npm-smoke.mjs is the deterministic product command for native review/oracle. Actual pack/global install into temp prefix/cache/home, loopback registry on port0 serving actual app plus exact parser dependency tarballs/integrity. No real home/global npm or credentials mutated. Verify all eight native choices, actual user-value preservation/idempotence/markers/JSONC/JSON5/YAML boundaries and newer-version update. Missing host readiness explicitly distinguished from artifact/integration proof. Developer smoke/registry helpers excluded from public tarball.

## Integration risk

PackageCli and HarnessAdapters share interfaces above, not files. PackageProof may author against contracts before implementations return. Builders must read existing patterns and external native-format sources first; send any contract correction via parent, not silently change a sibling API. Skip all test/build/lint/formatter executions mid-flight; parent executes after integration.
