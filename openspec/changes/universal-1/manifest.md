# Universal workflow #1 — requirements

User ask (verbatim): "Давай Внедрим это все нам" (briefing-раунды,
калибровка ~3K, benchmark с цифрами, npx skills) + "проверь работу доктора" +
"я хочу, чтобы у нас была умная установка, но бы детектила есть установлены ли
уже воркфлоу наш на этом компе, какая его версия, если установлена старая
версия, он бы обновлялся, если установлен другой workflow, с которым конфликтует
наш, мы бы об этом предупреждали и советовали удалять бы предыдущий воркфлоу
постоянно во время тасков бы себя проверяли правильно ли все работает корректно,
ничего ли мы не упускаем" + "интерактивный брифинг с раундами и джборд такой же,
как у них, мы тоже должны интегрировать" + "я хочу универсальный воркфлоу,
который займет первое место по остальным харнесам на Гитхабе" + "реальное должно
быть улучшение по всем параметрам по качеству кода, по экономии по конечному
результату, по поддерживаемости кода, по очищению мусора".

Wave 0 решения: conflicts=детект+WARN+совет (без карантина),
briefing=только CLI, skills=полный SKILL.md, bench=синтетический T2-прогон.
