# Why

The audit demonstrated disclosure of another task owner's release token, claim writes and context reads escaping through ancestor junctions, and permanently unclaimable ended tasks. Native review has no per-dispatch financial authority, rejects known zero cost, and can repeat completed work after receipt publication failure. Installation certificates do not establish live client behavior or a general code-quality advantage.

# What Changes

- Make existing task claims and packets canonical, confidential in diagnostics, scoped to their actual workspace and explicit checks, with safe release/reacquire transitions.
- Add explicit fail-closed model admission and bounded accounting at supported actual execution boundaries, without OpenRouter or an opaque fallback.
- Reconcile matching completed execution evidence without another provider turn; show prerequisites before spending.
- Verify real available local client/configuration paths, and document unavailable native execution separately.

# Impact

One local npm workflow remains the product. No new task server, database, dependency, arbitrary-shell sandbox, stale-lock eviction, global hash exemption or universal quality claim. Existing release remains blocked until independent accepted evidence is genuinely current. Source changes happen in contained isolated workers and one integration branch; human and historical evidence are preserved.
