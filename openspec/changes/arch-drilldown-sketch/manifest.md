# Требования — карта архитектуры с погружением (T2)

Запрос пользователя (verbatim):
«Окей смотри, во первых я просил детальный лайв дешборд как здесь, толко еще который
будет рисовать нам через excalidraw или аналог архитектуру вначале высокий слой но с
возможностью погрузиться все ниже и ниже.»

| ID | Verbatim user quote | Observable acceptance | Status |
|---|---|---|---|
| R01 | «детальный лайв дешборд как здесь» | Вкладка «Архитектура» живая: данные приходят из `/api/state` каждые 2 с, как остальные вкладки; счётчики файлов/строк и связи обновляются без перезагрузки страницы. Снимок (`--freeze`) по-прежнему рендерится автономно. | verified |
| R02 | «рисовать нам через excalidraw или аналог архитектуру» | Диаграмма рисуется в рукописной (Excalidraw) манере без внешних зависимостей: дрожащие штрихи, двойной проход, скруглённые прямоугольники. Кнопка «Скачать .excalidraw» отдаёт валидный файл (`type:"excalidraw"`, `version:2`), который открывается на excalidraw.com. | verified |
| R03 | «вначале высокий слой» | Открытие вкладки показывает проект и его модули (agent/core/tools/…) с числом файлов/строк и рёбрами между модулями; ни один файл и ни один символ не показан на этом уровне. | verified |
| R04 | «с возможностью погрузиться все ниже и ниже» | Клик по модулю → его файлы; клик по файлу → его символы (функции/классы/заголовки) с диапазонами строк и подсказками вызовов внутри файла. Хлебные крошки и «назад» возвращают на уровень выше; Esc — на уровень выше, а не закрывает страницу. | verified |

Не-цели: замена существующих режимов «Схема/Граф/Таблица» (они остаются), точный
разбор вызовов между файлами (граф вызовов — отдельная задача), правка кода
пользователя из дашборда.

Допущения (проверяемые): `tools/code-size.mjs:scanFile` уже разбирает JS/Python/PS1
и переиспользуется для символов; `.excalidraw` — открытый JSON-формат, экспорт без
сети; встроенных зависимостей для sketch-рендера не добавляем.
