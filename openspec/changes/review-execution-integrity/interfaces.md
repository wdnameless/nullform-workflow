## Native runtime repair: bounded review context

The implementation reviewer receives the complete changed-path inventory, pinned base revision and manifest, not duplicate eager copies of every patch and file. Complete source and per-path patches remain recoverable through the existing read-only `inspect_product` tool's bounded pages. Source authorization is unchanged; reviewer-only diff mode reads a literal authorized changed path, including deletions. Oracle cannot request diff mode or planning/acceptance artifacts. Git failures, credentials and outside-root paths fail closed. No truncation masquerades as complete source, no timeout increase conceals duplicated context, and no second inspection tool is introduced.

Public signature: `inspectProduct(options, requests)` returns pages `{path, kind, offset, nextOffset, totalBytes, contentHash, text}`. Native `inspect_product` accepts `requests: [{path, kind: 'source' | 'diff', offset?}]`, one to eight independent requests. Offsets are safe integer UTF-8 byte cursors; interior multibyte offsets and invalid UTF-8 fail explicitly. Following continuations reconstructs complete original source/diff, including giant escaped lines, BOM and CRLF. Aggregate rendered JSON stays below 32 KiB, including escaping and envelope metadata, so the SDK's 50 KiB spill cannot hide middle content. No scalar compatibility shim, artifact-ID coupling, SDK settings mutation or additional tool. Root/role/change and baseline remain operator-owned; every request uses the existing authorization and oracle-blindness gates.

Native `review-run` uses a bounded 900-second CLI deadline and 910-second process deadline so a full multi-file program review can finish its actual read-only tool round trips (measured 27–51 turns at ~17–40 s/turn provider latency). Source is retrieved on demand; benchmark generation/context/request/spending caps are unchanged.

Inspection completeness and latency were independently checked against installed SDK 18.6.1 by two read-only committee members. Consensus: batch independent reads and supply bounded recoverable pages; do not keep increasing deadlines or accept partial native verdicts. Historical failed sessions are retained as diagnostics, never reused as completed acceptance.
