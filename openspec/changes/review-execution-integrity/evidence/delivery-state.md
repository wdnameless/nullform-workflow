# Delivery state

Current execution results, acceptance status, billing distinctions and blockers are maintained in [acceptance.md](acceptance.md).

Original authority: [requirements manifest](../manifest.md). Deterministic output snapshots: [parent-checks.json](parent-checks.json). Native failure diagnoses: [native-cli-diagnosis.json](native-cli-diagnosis.json) and [native-timeout-projection.json](native-timeout-projection.json).

The progress report is an acceptance artifact; changing a report does not refresh source/test hashes or fabricate native execution receipts. Source changes still require fresh reviewer, Stage-B and independent oracle evidence.
