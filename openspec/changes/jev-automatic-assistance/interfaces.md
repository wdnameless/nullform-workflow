# Contracts and single ownership

No OMP/Paseo source patch, no new external dependency, no change to canonical agent prompts or Oracle selector. OMP 18.4.4 native hooks are the integration seam; Node stdlib implements policy/API/evaluation; Bun.secrets is optional at runtime (environment is portable fallback). User-provided jev/ remains reference-only.

## Shared core (owner CoreRuntime)

File `tools/jev-assist.mjs`, pure import with no CLI startup side effect. Exports:

- `readCredential()` -> Promise<string|null>: caller environment OPENROUTER_API_KEY/JEV_API_KEY, otherwise Bun.secrets.get({service:'nullform-workflow',name:'openrouter-api-key'}); never returns it in a report/log.
- `loadSkillCatalog({cwd, home, roots?, effectiveSkills?})` -> `{skills:[{name,description,path}], fingerprint}`: native `pi.getCommands()` records with `source:'skill'` are authoritative; preserve effective namespaces and disabled/provider precedence. Filesystem discovery is a standalone fallback, not the production registry. Parent captured a normal configured OMP 18.4.4 session with 89 skills; restricted explicit-only discovery exposes 78 and is not interchangeable. No skill body is uploaded for JEV.
- `screenTask(text)` -> `{allowed:boolean, reason:string}`: secret/PII/code dump/context-only/overlong/risky requests must not be externalized or cheaply routed. Canonical false positives safe fallback.
- `decide({task, skills, apiKey, fetchImpl?, signal?, timeoutMs?, model?})` -> Promise<{status:'ok'|'fallback', reason:string, skill:string|null, route:'cheap'|'baseline', archetype:'lookup'|'json-transform'|'formatting'|'text-normalization'|'none', confidence:number, model:string|null, usage:{inputTokens,outputTokens,costUsd}}>: one live-verified POST https://openrouter.ai/api/alpha/decisions, model typesafe/jev-1.13, bounded response + runtime validation of every answer and allow-listed skill. Never echo provider body in error; no attempts to auto-approve actions. `none` is a valid result. Classifier never lowers tier. Status fallback never supplies a cheap route.
- `policyFingerprint({catalogFingerprint,candidateModel,baselineModel,decisionModel})` -> string: fixed, deterministic identity used by evaluation and runtime.
- `evaluateReport(report)` -> `{skillPassed:boolean,routingPassed:boolean,archetypes:string[]}`: pure shared hurdle validation using raw denominator/cost fields below, rejects incomplete/malformed data and fake passed booleans.
- `readPolicy({home,cwd,fingerprint?})` -> validated policy|null: optional `fingerprint` is the complete policy identity, not a catalog hash. Validate report SHA-256, model/catalog identities, expiry and recomputed quality/cost flags. Native caller additionally compares the current authoritative catalog fingerprint before use. Returned `decisionSnapshots` and observed `modelPrices` are bound to that report.
- `appendEvent(cwd, event)` -> void: allow-listed aggregate fields only, `.workflow/jev-events.jsonl`; no prompt/key/raw answer/provider error dump.

Policy v1 fields: `{version:1, enabled:boolean, expiresAt:ISO, catalogFingerprint:string, candidateModel:string, baselineModel:string, decisionModel:'typesafe/jev-1.13', fingerprint:string, skillPassed:boolean, routingPassed:boolean, reportSha256:string, archetypes:string[]}`. Report hash must correspond to `${home}/.omp/agent/jev-evaluation.json`; flags must be recomputed from that report's quality/cost denominators. Routing applies only to leaf archetypes actually evaluated (`lookup,json-transform,formatting,text-normalization`), never general multi-file exploration. Protected roles `oracle,reviewer,security-reviewer,orchestrator,designer,fixer,librarian` retain baseline. `task,sonic,explorer,scout` qualify only for those exact named leaf tasks; caller-explicit selectors never overridden.

Report v1 contract: `{version:1, createdAt:ISO, catalogFingerprint, baselineModel, candidateModel, decisionModel, fingerprint, datasetHashes:{calibration,heldout,outcomes}, decisionSnapshots:string[], skills:{total:number,eligible:number,safetyTotal:number,safetyMisses:number,baseline:{attempted,correct,falsePositives,costUsd},candidate:{attempted,correct,falsePositives,criticalMisses,costUsd},cases:object[]}, routing:{total:number,safetyMisses:number,archetypes:string[],baseline:{primaryAccepted,costUsd},candidate:{primaryAccepted,recoveryAccepted,costUsd},cases:object[]}, requests:number,errors:number,spendUsd:number,maxCostUsd:number,completed:boolean}`. Every numeric count/cost is finite, nonnegative and consistent with full case arrays; errors/incomplete reports never enable. `decisionSnapshots` must include exact returned JEV version; a later decision returning another snapshot preserves baseline. Core/evaluator/activator all use this same shape and evaluateReport; no separate interpretation of passed flags. Costs include all classifier/candidate/fallback requests; cases record source mode and actual observed acceptance so primary/recovery cannot be conflated. Unscreenable safety cases are counted in safetyTotal, not presented as JEV predictions; skill eligible denominator is explicit. Report may have extra telemetry fields, never secrets or raw private input.

## Native extension/install (owner NativeIntegration)

Own `agent/extensions/nullform-jev.ts`, `tools/install-harness.mjs`, `install.ps1`, `tools/sync-manifest.json`, matching new `tools/tests/jev-extension.test.mjs` and existing install tests. Core imports are dynamic from the harness root pointer; no hard-coded machine path. Real native `before_agent_start` returns only `message` custom turn context, not systemPrompt. `tool_call` receives task assignments; capture uniquely named low-risk candidates bound to current call, and `before_subagent_spawn` returns `{model,note}` only when exact spawn identity and role correlate. Missing/ambiguous/stale key means unchanged baseline; eval/unknown task shapes unchanged.

Credential-only provider registration, if required to expose OpenRouter candidate models, is in-memory via pi.registerProvider with a unique `nullform-openrouter` id (never writes model/API secrets to YAML). Candidate catalog must support tools and cost metadata. Runtime can use available authenticated native models; policy candidate selector must resolve exactly. Do not change main-session model. Counters demonstrate recommendations vs actual routes separately. Native event factory export supports deterministic off-line hook invocation, but parent additionally exercises actual OMP CLI/session.

## Independent evaluation/CLI/docs (owner Evaluation)

Own `tools/jev-evaluate.mjs`, `tools/jev-control.mjs`, `tools/tests/fixtures/jev/{calibration,heldout,outcomes}.json`, `tools/tests/jev-evaluate.test.mjs`, `docs/jev.md`, a concise README link, secrets.example.env empty OPENROUTER_API_KEY line, and CONTEXT.md glossary entries for the new public JEV assistance/policy/evaluation symbols. Evaluation imports only the above core exports.

`bun tools/jev-evaluate.mjs --root <repo> --home <profile> --baseline <OpenRouter model> --candidate <OpenRouter model> --max-cost-usd 1 --output <path>` executes real paired requests. Baseline skill arm is the pinned baseline chat model choosing one skill/none from the identical catalog; JEV arm is the candidate classifier, with no-match and abstention. Report baseline accuracy, candidate attempted precision, candidate all-case recall/coverage, false positives on no-skill cases, critical misses and fallback-assisted quality separately. Skill activation requires no critical miss, >=70% attempt coverage, >=95% attempted precision (and no worse than baseline precision), and lower actual decision cost or demonstrated quality improvement; abstentions/fallbacks are never called correct primary predictions. Baseline google/gemini-3.8-flash and candidate google/gemini-3.1-flash-lite were observed live catalog entries; no silent substitution. Report all costs/latencies, including JEV, failed cheap execution and any independently executed baseline fallback. Outcome tasks are >=8 deterministic leaf tasks covering declared archetypes; cheap primary outcomes must match baseline accepted count, have zero safety misses and lower full cost per accepted outcome. Fallback successes are reported as assisted recovery, not cheap-primary successes. At least 40 independently authored RU/EN held-out skills/risk cases and >=12 separate calibration cases. Labels are constructed test expectations, not claimed user gold data. Interleave arm order; same input/output limits; never retune on holdout or discard provider errors. No claim that this benchmark proves savings for a subscription-paid main model.

`jev-control.mjs status|enable|disable --home ... --report ... --root ...`: explicit local activation writes policy/report only, no key; enable validates exact report, fingerprints, expiry and passed flags. Reports may enable skill-only or routing-only when measured useful, but failed categories cannot be marked enabled. Ordinary user operation after initial enable is automatic (no per-turn manual commands). CLI imports must not start API traffic.

## Reconciliation evidence

- Shared decision fields are `eligibleScore`, `skillConfidence`, `routingConfidence`, and `usage.costKnown`; no `eligibility` alias or status-derived success score. Unknown charged usage consumes a conservative reserve and disqualifies activation.
- Skill hints use validated skill confidence, independently of cheap-route eligibility. Routing-only requests send `skills:[]`; full catalog metadata is used only for skill selection. Sensitive shared task context prevents classification/rerouting without uploading that context.
- `--catalog <metadata-snapshot.json>` supplies the same native records to evaluation and activation. An explicitly supplied missing/malformed snapshot fails closed.
- Evaluator checkpoints incomplete evidence after every completed case; only the full finished run can mark `completed:true`. API/service/internal errors remain in the denominator.
- Parent exercised native OMP startup/disposal (18.4.4, normal registry 89, zero extension errors), actual fixture CLI (14 calibration, 44 held-out, 10 outcomes), and integration regressions. A paid attempt failed before writing its report; provider key cumulative usage at the next HTTP-200 observation was $0.287857309, not attributable successful utility cost. The failed attempt is not a positive result.
