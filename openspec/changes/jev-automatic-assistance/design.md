# Design

Reuse OMP 18.4.4 before_agent_start message injection and before_subagent_spawn model replacement, not Paseo provider switching or a patch to OMP. Read skill name/description from the effective registry; do not upload skill bodies, source files or transcripts. Keep the stable system/catalog prefix untouched. Classifier output is advisory context for skills and a constrained execution selector for exact eligible child tasks; deterministic code owns permission and policy.

OpenRouter POST /api/alpha/decisions with typesafe/jev-1.13 was verified live. Use bounded request/response, deadline and schema validation; invalid answers/timeouts/errors preserve current routes. Pin the decision model and record actual returned version. No silent TLS bypass. Screen all outbound task and skill metadata; a detected secret or sensitive input triggers no classification request. Skip continuation-only messages and large code dumps.

Native before_subagent_spawn receives agent/modelRole/patterns/spawnKey but NOT the task. Correlate task assignments observed by tool_call to exact named spawn identity, role, parent invocation and freshness. Unnamed/ambiguous/eval spawns retain their original models. Never downgrade protected roles, main-session model, explicit caller selector, or high-risk assignment even if the classifier suggests cheap. Availability and price metadata must be observed; an unknown model/cost cannot become a fabricated cheap route.

Credentials: Bun.secrets stores this user's supplied key in Windows Credential Manager (local persistence); portable environment variable fallback for CI/non-Bun Node contexts. No plaintext config for secrets and no credentials in child task instructions. Runtime-only custom provider may resolve vault credentials for approved child model execution, without modifying YAML or approval settings.

Evaluation: 12+ separate calibration cases, 40+ independently authored constructed RU/EN held-out skill/risk cases, and >=8 deterministic leaf-task outputs across explicit archetypes. The baseline chat model chooses skill/none from the same catalog; report accuracy, attempted precision, recall, coverage, false positives and critical misses. Cheap primary outcomes exclude successes supplied by baseline fallback; assisted recovery and its costs are separate. Keep all provider errors in denominators; include JEV and full fallback costs, interleave arm order and never retune on holdout. Skill activation requires zero critical miss, >=70% coverage, >=95% attempted precision no worse than baseline and lower measured decision cost or a quality improvement. Routing requires primary accepted count no lower than baseline and lower full cost per accepted outcome, limited to evaluated archetypes. These are scoped constructed-data/model-pair results, not proof of savings on the subscription/current main model. Fingerprints and expiry force safe fallback. Live proof cap $1.

No new external runtime dependency, new UI or mandatory interview/gate. Provide a small activation/status CLI and concise documentation. The user-provided jev/ tree stays unmodified and is not committed wholesale. Full smoke exercises real native hooks, child model identity, fallback and opt-out. Record sanitized live API cassette through existing replay.mjs for network acceptance.
