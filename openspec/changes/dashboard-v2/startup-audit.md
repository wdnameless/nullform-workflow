## 2. Анализ доказательств и кандидаты на срез

На основе аудита сессий `node tools/usage-audit.mjs --days 90 --top 20 --json` (276 сессий, 122 230 строк логов):

1. **`playwright`**:
   - 0 вызовов за 90 дней во всех сессиях.
   - Запуск через unpinned `npx` занимал **9.21 с** (проверка реестра npm на каждый холодный запуск).
   - Для браузерных задач используется `chrome-devtools` (12 вызовов) и встроенный агентский браузер.
   - **Решение:** УДАЛИТЬ из живого `mcp.json`. В примере `mcp.json.example` закрепить точную версию `1.0.12`.
2. **`codegraph`**:
   - 0 вызовов за 90 дней.
   - Локальный бинарник отсутствует в системном `PATH` (`where codegraph` возвращает `INFO: Could not find "codegraph"`). Запускался через абсолютный путь к кэшу Hermes.
   - `install.ps1` уже содержит условие сброса `codegraph` при отсутствии команды в PATH.
   - **Решение:** УДАЛИТЬ из живого `mcp.json`.
3. **`context7`**:
   - 11 вызовов за 90 дней (активно используется для поиска документации).
   - Запускался без версии: `npx -y @upstash/context7-mcp` → сетевой опрос реестра npm.
   - **Решение:** ОСТАВИТЬ, закрепить точную актуальную версию `@upstash/context7-mcp@4.1.1`.
4. **`chrome-devtools`** и **`dap-debugger`**:
   - Активны, версии уже были зафиксированы (`1.9.0` и `0.1.12`). Оставить без изменений.
5. **`codebase-index`**:
   - Локальный бинарник `opencode-codebase-index-mcp` присутствует в PATH (`D:\npm-global\opencode-codebase-index-mcp`), откликается за 0.67 с, не висит на таймауте. Оставить.
6. **`hindsight`** и **`crawl4ai`**:
   - Высокая активность (31 и 21 вызов), быстрый отклик (<0.3 с). Оставить.

## 5. Корневой анализ оставшихся задержек старта OMP

Замеры и логи показали два независимых слоя задержки старта:
1. **MCP Subprocesses**: Снижено с **23.47 с** до **14.31 с** (-39%). Устранены сетевые запросы npx к npm registry благодаря строгому пину версий.
2. **Фаза `loadExtensions`**: Занимает от 12 до 25+ секунд.
   - Причина 1: 14 активных OMP-плагинов в `~/.omp/plugins/package.json`.
   - Причина 2: Автоматическое обновление маркетплейсов (`cocoindex-code` git-кэш в `marketplaces.json`).
   - Аудит использования плагинов показал: плагин `pi-gh-cli` имеет **0 вызовов за 90 дней** и является кандидатом на удаление из `agent/plugins.json`.
