Every worker owns only its assigned files in a separate worktree and skips all builds, test runs, linters and formatters. Parent integrates disjoint commits, executes focused red/green smoke and the full suite once, then deploys changed harness files and obtains blind acceptance against manifest. No Oracle artifact is considered verified by the same agent that wrote it.
