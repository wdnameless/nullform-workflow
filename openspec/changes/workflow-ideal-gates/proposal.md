# Proposal — закрыть обходы гейтов без новых слоёв

Аудит нашёл обходы, позволяющие пронести непроверенные изменения мимо приёмки, и две зоны потери данных: prune удаляет внешние файлы через symlink, висячий корень обходит preflight, оракул в одном коммите с кодом слеп, бинарный diff не считается в лимит, переименование проверяется буквальной строкой, `install.ps1` портит шаблоны репо.

Чиним существующие `sync-prune.mjs`, `sync.mjs`, `workflow.mjs`, `install.ps1` минимальными правками с красными регрессиями на каждый repro. Новых зависимостей, слоёв и обязательных артефактов нет. Тесты детерминированы на временных фикстурах; jail для symlink — OS temp.
